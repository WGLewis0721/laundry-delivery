# Iconography — 21 canonical utility SVGs

**Source of truth:** [`assets/icons/`](../../assets/icons/) contains individual, new 24×24 SVG utility glyphs. [Rendered icon sheet](../evidence/icons/soapbox-utility-icon-sheet.svg) and [HTML gallery](../gallery/index.html#icons) show all 21 names.

## Specifications
- Canvas `viewBox="0 0 24 24"`; stroke `1.75`, `currentColor`, round caps/joins, no fill by default.
- Optical alignment, appropriate `alt` when standalone meaningful; use `aria-hidden` when text already supplies meaning. Never rely on icon alone for critical validation.
- Preserve branded [olive sprig](../../assets/img/decor-olive-sprig.svg) as separate decorative art.
- Symbols here are **review candidates**; existing inline SVGs in the live site have not yet been migrated. Don't silently swap all live icons without visual QA.
