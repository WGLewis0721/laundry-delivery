# Brand Board

**Visual reference:** [Open the rendered brand board](brand/brand-board.html) · [SVG preview](evidence/brand-board/brand-board.svg) · [PNG export](evidence/brand-board/brand-board.png)

The board presents the **current implemented** identity, rather than guessing at a new one. It uses the real header/footer logo image exports already in the repository and live site colors.

## Brand character
Comfort without fuss. Contemporary editorial typography, warm ivory whitespace, folded-linen photography, calm sage surfaces and dark olive accents. Avoid busy gradients, generic glossy corporate visuals and misleading before/after imagery.

## Authority
- **Implemented:** current color tokens, Cormorant Garamond/Inter/Oswald, logo image exports, site imagery.
- **Requested but unavailable:** commercial OKANA/ENRIQ fonts and original external brand board.
- **Proposed:** normalized utility-icon reference set, future favicon/export system, any refinements not present in the actual website.

No approval is implied by inclusion in this reference package.
