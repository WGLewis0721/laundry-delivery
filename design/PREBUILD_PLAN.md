# Design-system PR delivery plan and implementation boundary

This PR contributes real branded design proofs and source-derived screen wireframes, **not** a deployed redesign or functioning booking/payment integration.

## Produced assets
- Existing logo imagery in a viewable gallery, rendered SVG brand board and documented palette/type.
- New reusable SVG utility icon set + sheet; component gallery demonstrating accessible HTML interactions and correct brand styling.
- 15 page specifications, 30 responsive structural SVG wireframes and companion PNG previews (generated from design SVG source).

## Reversible follow-up work
- Client reviews and selects actual approved fonts, logo masters, visual directions, and specific component changes.
- Then implementation edits the affected page(s) in isolated PRs with real browser screenshots + regressions; do not silently normalize existing CSS or affect Square.

## Decisions still open
