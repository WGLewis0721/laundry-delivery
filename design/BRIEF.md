# Soapbox Caddie — Website Design Brief

**Status:** Current-site reference; client approvals pending where noted.
**Product:** Laundry pickup and delivery in the River Region, Alabama.
**Primary message:** “Choose peace, not laundry.”
**Primary visitor action:** Check eligibility and request a pickup.
**Reference:** Existing production HTML/CSS in this repository. Approved homepage composition is retained.

## Experience
- Calm, welcoming, editorial; generous breathing room with clear conversion paths.
- Ivory page surfaces, dark readable ink, olive highlights, restrained sage action surfaces, taupe hairlines.
- Self-hosted fonts. Maintain the current type fallback until licensed OKANA and ENRIQ are provided and approved.
- Functional pages: homepage, process, plans, services, service area, about, FAQ, estimate, schedule, confirmation, status, account, login, privacy and terms.
- No changes to prices, account capabilities, booking transmissions, payment, or service eligibility are authorized by this visual package.

## Current constraints
- Brand board referred to in source code but no authoritative editable copy in this repo.
- OKANA and ENRIQ appear in client-requested font requirements but the licensed files are not present.
- Original, editable logo master and photography/illustration release registry are not included.
- Existing SVG icons are embedded on pages; a reusable 24px reference set is supplied here for review, not automatically installed.
- Client copy and any transactional promises must be checked against the business workflow before launch.

## Acceptance
Each visual component must trace to an existing site element or be marked as a proposal. Every page has a desktop and mobile layout reference. No brand update ships without approval and responsive/interaction validation.
